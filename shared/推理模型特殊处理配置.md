# 推理模型特殊处理配置

小米 MiMo 和 DeepSeek v4 是推理模型，有非标准行为需要特殊配置：

**小米 MiMo**：流式响应先吐 reasoning_content 再吐 content，OpenClaw 的 xiaomi provider wrapper 有 bug (issue #60304，42天未修)。Workaround：改 provider 名为 mimo + 走 LiteLLM 转发，绕过 OpenClaw 的 xiaomi wrapper。

**DeepSeek v4 thinking mode**：要求多轮对话必须回传 reasoning_content，LiteLLM 默认过滤掉会导致 API 报错。Workaround：litellm_config.yaml 添加 `merge_reasoning_content_in_choices: true`。

普通模型（GPT、Claude、通义千问等）无需这些特殊处理。问题都是上游已知 bug，不是我们修改源代码造成的。
